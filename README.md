# link-tree

Personal linktree for Don Barger — a simple, mobile-friendly page linking to tools built at the intersection of innovation, technology, and faith.

**Live:** https://link-tree.donbarger.com

## Stack

Single static HTML file. No build step, no dependencies.

## Deployment

Served via nginx on DigitalOcean. To update, edit `index.html` and run the deploy script:

```bash
./deploy.sh
```
